Cloud API: Dockerized Web Application on AWS

A containerized REST API project focused on cloud deployment, stateless architecture, and secure endpoint delivery using Docker and AWS infrastructure.

View Project Screenshots View Project Report Download Report Back to Projects
Overview

What this project involved

This project involved deploying a containerized REST API to AWS EC2 using Docker and Amazon ECR. The application handled basic user authentication using JWT and executed CPU-intensive operations. It was designed to be stateless, scalable, and production-ready using cloud-based infrastructure and best practices.

My Role

Where I contributed

  • Designed and implemented the full deployment pipeline using Docker and AWS
  • Configured the AWS EC2 instance with firewall rules, SSH access, and Linux environment setup
  • Containerized the REST API and pushed the image to Amazon ECR
  • Built and demonstrated the CPU-intensive endpoint with logging and JWT protection
Key Features

Main project outcomes

  • RESTful API endpoints secured with JWT tokens
  • Stateless architecture using cloud storage and session-less logic
  • Custom Docker image with a CPU-bound background task
  • Deployed via EC2 and tested for scalability and fault tolerance
